The **boolean type** in Python is called `bool` and has exactly two possible values: `True`{.python} and `False`{.python} (with a capital "T" and "F").

# Creating Boolean Values

You can create boolean variables by directly assigning `True`{.python} or `False`{.python}:

```py-cell
flag = True
active = False

print(flag)
print(active)
```
